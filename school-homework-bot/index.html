School Homework Bot

Personal educational assistant for family use.

About the application

School Homework Bot is a private, non-commercial Telegram application designed to help family members organize school schedules and homework assignments.

Google Classroom integration

The application uses Google OAuth 2.0 and the official Google Classroom API to access authorized educational information.

Google Classroom access is read-only. The application does not modify assignments, grades or student submissions.

Application status

The application is currently under development. Access is intended for authorized family members.
